## Entry

> I rerouted you through a wedding because the map swore it was a shortcut, and honestly the bride looked so happy I didn't want to ruin it by turning around.

The GPS's own excuse, in its own voice, for sending the driver down the wrong road — no setup, no dialogue tags, just the excuse. One line, 156 characters.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `MAKEFUN_OUTPUT_DIR` when set, otherwise to `/output`. The program is deterministic: it writes the same text on every run, and validates the gate (one line, 1–200 characters, not whitespace only) before writing, exiting non-zero on failure.
